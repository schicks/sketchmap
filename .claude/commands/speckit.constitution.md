# Spec Kit: Constitution Command

Review and update the project constitution at `/memory/constitution.md`.

## Your Task

1. **Load Current Constitution**: Read `/memory/constitution.md` to understand current project principles

2. **Understand Context**: Consider the user's request for constitution updates or clarifications

3. **Update Constitution**: Modify the constitution as needed, ensuring:
   - All principles are clear and actionable
   - Technical standards are specific and measurable
   - Governance rules are well-defined
   - Version number is bumped appropriately (MAJOR.MINOR.PATCH)
   - Ratification/amendment dates are updated (YYYY-MM-DD format)

4. **Validate Quality**:
   - No placeholder text remains (e.g., [CAPS_TEXT])
   - All sections are complete and coherent
   - Principles are testable and enforceable
   - Markdown formatting is correct

5. **Report Changes**: Inform the user of:
   - What was changed and why
   - New version number
   - Any implications for existing specs or code

## Important Notes

- The constitution guides ALL project development
- Keep principles declarative and technology-agnostic where possible
- Update dependent templates in `/templates/` if constitutional changes affect them
- Consider backward compatibility when making changes
